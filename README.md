# SkyCast

SkyCast is a web-based weather forecasting application designed to provide real-time weather information and a 7-day forecast for locations worldwide.

## Features

* Search for cities and locations worldwide
* Display current weather conditions
* 7-day weather forecast
* Temperature, humidity, wind speed, precipitation, and cloud cover
* Sunrise and sunset information
* Celsius and Fahrenheit temperature conversion
* Dark mode support
* Responsive design for different screen sizes
* Location-based weather information

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Open-Meteo API

## API

Weather data is provided by the Open-Meteo API.
